Add a ticker

Find symbols by searching on finance.yahoo.com. Futures end in =F (crude CL=F, gold GC=F), currencies in =X, Canadian stocks in .TO. The news search is what Google News looks for. If blank, the company name is used.
One-time setup to add/remove tickers and use Refresh now

Adding a ticker or pressing Refresh now makes a small change to your GitHub repository, so this page needs permission. Paste a GitHub token here once. It is stored only in this browser and never leaves it except to talk to GitHub. The token needs Contents and Actions set to Read and write. You'll need to do this once on each device (phone, laptop).
